Inside the computer, everything is
stored as numbers. Graphics, sounds,
words on the screen - it's ALL numbers

And, since it's all numbers, when we
programmers want to represent something
from the real world, we need to 'encode'
those real world things into numbers.
Codes are so important to the world.
Some programmers love working with codes
so much, they call themselves 'coders'!

To 'codify' something in the real world
in the computer is to make 'codes' that
everyone can agree on and understand.
For example, in most computers, there
are standard numeric codes for symbols
that are PRINT'ed on the screen. Every
letter you see on the screen has a
numeric code that goes with it!

Everyone agrees that code number 97 is
the lowercase letter 'a'. When you press
the \uF112 button on your keyboard, that
gets input to the system as the code
number 97. Learn more about PRINT'ed
symbol codes in the %kidscii% topic and
see what codes do what
