          About Result Codes
          \u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E\u203E
Syscalls and keywords may do processing
in the background while other things are
going on. These background jobs usually
evaluate to a record that has a status
field. When this status field changes,
the background job will SIGNAL the
record. Use a LISTEN block on the
record, and check the status field on
the record. It should contain one of the
result codes in the table below.

  code  \179         description

Notes:
 - 'mxi' in the table above is short
   hand for Math.mxi32
 - Negative result codes are errors. A
   Comfy program can test for LT 0 as a
   quick check of a result code to see
   if an error occurred
 - Result code of zero indicates success
 - In scenarios where a syscall or
   keyword does not error, but is only
   able to partially perform its job,
   READ_PARTIAL or WRITE_PARTIAL are
   the result code
