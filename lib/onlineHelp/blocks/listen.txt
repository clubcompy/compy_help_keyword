LISTEN - react when record is SIGNAL'ed

Grammar:
 "LISTEN" alias "," rec
    .
    . 0-or-more comfy statements/lines
    .
 "END"

Arguments:
 - alias: <symbol> variable name for rec
   only valid inside the LISTEN block
 - rec: <record> a record to listen to

Evaluates to:
 <listener_key> identifies the listener

Notes:
 - LISTEN'ers to records will have their
   code blocks run on each SIGNAL to rec
 - VCE will make a clone of rec at the
   time rec is SIGNAL'ed. Inside the
   LISTEN block, this clone of rec
   is then assigned to alias
 - alias is a variable name for rec that
   is only valid inside the listen
   block's scope. This is known as a
   "local variable"
 - All records in the Comfy language can
   be SIGNAL'ed and LISTEN'ed
  \156 Only the VCE system may SIGNAL
    built-in records (e.g. Cursor)
  \156 Only the user's Comfy code may
    SIGNAL user-created records
 - Pass the listener_key to CANCEL to
   stop the LISTEN block from being
   triggered by future SIGNAL's

See also:
 - %SIGNAL%
 - %CANCEL%
 - %builtins%
