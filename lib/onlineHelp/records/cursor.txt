       About the Cursor Record

The Cursor record tracks the information
managed by the flashing cursor that
indicates where the next printed
character appear on the display and
what display attributes (colors, invert,
ghost) the next printed character will
have

Record<$Cursor> definition:
 - Signals when: approximately every 10
   milliseconds but only if a field on
   the Cursor record has changed

Notes:
 - If Display.vw is true, Cursor will
   cause PRINT keywords (incl. PRINTLN
   and SAY) to pause whenever automatic
   line break or newline control codes
   are painted to the Display. Whenever
   Cursor.idle field is true, no PRINT
   keyword lines are waiting to paint

   If Display.vw is false, PRINT
   keywords will not pause for next
   frame on new lines and paint as much
   as possible within available time

 - The TAG keyword does not paint to the
   Display via Cursor (it makes direct
   changes to the Display's Playfields)
   and does not wait for new Display
   frames like PRINT keywords do

Cursor-manipulating keywords:
 - %MOVE%
 - %FGCOLOR%
 - %BGCOLOR%
 - %PRINT%
 - %PRINTLN%
 - %SAY%
 - %FLIP%
 - %CLEAR%
 - %RESET%

See also:
 - %SELECT%
 - %VWAIT%
 - %Display%
 - %codes%
