The Turtle record provides information
about the turtle sprite which can move
about its vector graphics plane drawing
fine, colorful vectors that appear as
lines on the Display

Record<$Turtle> definition:
 - Signals when: never

Notes:
 - Turtle x and y fields are measured in
   VCE Display pixels as projected onto
   the physical screen and describe the
   precise point on the Display where
   the Turtle is situated

   The coordinate system has the origin
   (x: 0, y: 0) set at the center of the
   VCE Display. Positive x values are to
   the right of center and negative x
   values are to the left. Positive y
   values are above the center and
   negative y values are below

 - The turtle's vector graphics plane is
   always visible, but the turtle sprite
   can be hidden and shown (using the
   SHOW and HIDE keywords)

 - The vector graphics plane is
   sandwiched between Playfields 3 and
   4. This allows vector and raster
   graphics to coexist in the same
   scene, with characters from
   Playfields 0-3 appearing behind the
   turtle graphics and characters from
   Playfields 4-7 appearing in-front of
   the turtle graphics. This allows for
   some amazing artwork and fancy
   diagrams!
